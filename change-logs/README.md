# Change Log Index

This folder stores a per-file change log for the School OS workspace.

## Format
Each tracked file gets its own markdown file under this directory.

Example:
- `change-logs/frontend-src-components-layout-teacher-TeacherLayout.md`

## Rules
- Create or update one log file whenever a workspace file is changed.
- Record the date, summary, and reason for each modification.
- Keep entries concise and implementation-focused.
